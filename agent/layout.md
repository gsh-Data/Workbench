# 个人专属全栈工作台 V4.0 架构与交互设计方案

## 一、 项目概览
本项目旨在打造一个专属于个人的全栈工作台，作为日常开发、知识沉淀与效率管理的“超级控制中心”。系统采用 Web 架构，配合桌面快捷脚本实现“类 App”沉浸式体验。

**🚀 V4.0 核心更新：**
1. 确立经典的“厂”字型后台管理布局结构。
2. 引入实时天气与强提醒消息机制。
3. 明确初始三大核心模块：全局仪表盘、知识库、音乐台。

*   **核心技术栈：** Vue 3 + Tailwind CSS + Node.js (文件存储)

---

## 二、 页面布局结构 (厂字型设计)

系统整体采用最符合操作直觉的经典“厂”字型布局：顶部 Header、左侧 Sidebar 菜单栏、右侧主容器 Container。

### 1. 顶部栏 (Header)
*   **左侧 (Logo区)：** 显示个人工作台标识及折叠/展开 Sidebar 的汉堡包按钮。
*   **右侧 (工具与状态区)：**
    *   **天气挂件 (Weather Widget)：** 
        *   集成第三方天气 API（如和风天气或 OpenWeather）。
        *   实时显示当前所在地的天气图标、温度和简要描述。
    *   **消息中心 (Notification Icon)：**
        *   铃铛图标，带未读数量红点徽标 (Badge)。
        *   点击下拉展示最近的任务执行列表和系统通知。
        *   **强弹窗机制：** 前端与后端保持 WebSocket 或 SSE 连接。当后端的定时任务触发并执行完毕（或报错）时，立刻向前台推送消息，前端接收后无视当前所处页面，全局弹出 Notification 通知框。

### 2. 左侧菜单栏 (Sidebar / Left)
固定在左侧的垂直导航菜单，支持展开与收起以最大化工作区。
目前规划三大一级菜单：
1.  **全局仪表盘 (Dashboard)**
2.  **知识库 (Knowledge Base)**
3.  **音乐台 (Music Station)**

### 3. 主内容区 (Container)
右下角占据最大面积的路由视图渲染区域，采用平滑的路由切换动画，配合纯白或浅灰色背景，突出内容本身。

## 三、 核心模块功能定义 (初始规划)

### 1. 全局仪表盘 (Dashboard)
*   **定位：** 信息的聚合中心与快速操作入口。
*   **内容规划：**
    *   **欢迎卡片：** 显示当前时间、日期以及简短的问候语。
    *   **快捷面板：** Tiptap 编辑器快速入口，随时随地记录灵感。
    *   **待办清单 (Todo List)：** 极简的任务列表，支持快速勾选完成，数据存入本地 JSON。

### 2. 知识库 (Knowledge Base)
*   **定位：** 个人数字大脑，沉浸式的内容创作与管理。
*   **内容规划：**
    *   **Markdown 沉浸式写作：** 深度集成 Tiptap，支持全屏模式。
    *   **物理文件管理：** 左侧（或抽屉式）显示服务器 `docs` 目录下的文件夹和 `.md` 文件树结构，点击即预览/编辑。
    *   **代码片段库 (Snippets)：** 内嵌高频代码片段模块，支持标签化分类和一键复制。

### 3. 音乐台 (Music Station) (新增)
*   **定位：** 工作时的沉浸式伴侣。
*   **内容规划：**
    *   **白噪音/Lo-Fi 电台：** 收集常用的在线白噪音资源或开源的 Lo-Fi 音乐流地址，嵌入工作台中，工作时一键开启背景音。
    *   **悬浮迷你播放器：** 切换到其他模块（如知识库写作）时，音乐台以极小的悬浮窗或在 Header 栏展示播放控件，不打断工作流。
